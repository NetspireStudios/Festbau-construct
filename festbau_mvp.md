# Festbau Investor-Grade Website — MVP Specification

> **Purpose of this file**
This Markdown file is the single source of truth for generating the **Festbau investor-grade website MVP**.
Cursor (or any code-generation agent) must **read this file first** and follow it strictly when creating the site.

The goal is a **fully functional, professional, multi-page website** with working navigation, internal links, CTAs, and placeholder assets (no empty image slots).

---

## 1. Global Rules (Must Follow)

### 1.1 Functional Requirements
- All pages must be real routes (no dead links)
- Navigation must work forward/backward across all pages
- All CTA buttons must link to valid pages or actions
- Case studies must link correctly from Projects → Case Study pages
- No placeholder text like "Lorem Ipsum"

### 1.2 Design & Styling Rules
- Follow the **uploaded design template file** for layout, spacing, typography, and color usage
- Clean, institutional, investor-grade aesthetic
- Minimal animations only (subtle hover / fade)
- Consistent grid, spacing, and image ratios
- Use **sample/stock images** everywhere an image is required — never leave empty image blocks

### 1.3 Navigation Rules
- Top navigation (max 6 primary links)
- Persistent primary CTA in top-right: **Get a Consultation**
- Footer present on all pages

Primary Nav:
- Home
- About
- Services (dropdown)
  - Design-Build
  - General Contracting
  - Project Management
  - Modular & Prefabrication
- Projects
- Qualifications / Resources
- Contact
